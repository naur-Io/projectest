# Arsenal Patriota 2026

Landing page estática desenvolvida com Tailwind CSS e HTML5 com foco em alta conversão e responsividade.

## 🚀 Live Demo
Acesse o site publicado via GitHub Pages:
[https://naur-io.github.io/projectest/](https://naur-io.github.io/projectest/)

## 📁 Estrutura do Projeto
- `index.html`: Landing page principal responsiva com Tailwind CSS e scripts interativos
- `assets/`: Imagens e capas dos eBooks 3D
- `.nojekyll`: Instrução para o GitHub Pages ignorar o Jekyll e acelerar os deploys

## 🛠️ Tecnologias
- HTML5 / CSS3
- Tailwind CSS via CDN
- Vanilla JavaScript
